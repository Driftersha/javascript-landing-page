# Briaton Landing Page

Адаптивный интернет-магазин светотехники с каталогом товаров, фильтрацией, корзиной, слайдером и формами обратной связи.

## Стек

- HTML5
- SCSS/CSS
- JavaScript ES Modules
- JSON для локальных данных товаров
- Swiper
- Tippy.js
- JustValidate
- ESLint
- Prettier

## Структура проекта

```text
.
├── index.html              # Главная страница с каталогом
├── checkout.html           # Страница оформления заказа
├── privacy.html            # Политика конфиденциальности
├── personal-data.html      # Согласие на обработку персональных данных
├── data/data.json          # Данные товаров
├── css/style.css           # Скомпилированные стили
├── scss/                   # Исходные SCSS-файлы
├── js/
│   ├── api/                # Получение данных
│   ├── components/         # UI-компоненты
│   ├── pages/              # Инициализация страниц
│   ├── services/           # Логика корзины и хранения
│   └── main.js             # Точка входа
├── images/                 # Изображения и SVG-спрайт
└── fonts/                  # Локальные шрифты
```

## Возможности

- загрузка товаров из `data/data.json`;
- фильтрация товаров по типу;
- сортировка каталога;
- пагинация списка товаров;
- добавление товаров в корзину;
- хранение корзины в браузере;
- удаление товаров из корзины;
- оформление заказа с валидацией формы;
- выбор города;
- бургер-меню каталога;
- аккордеон FAQ;
- слайдер товаров дня.

## Запуск проекта

Проект использует `fetch` для загрузки `data/data.json`, поэтому его лучше открывать через локальный сервер, а не напрямую как файл.

Установите зависимости:

```bash
npm install
```

Запустите любой локальный сервер из корня проекта. Например, если установлен Live Server в VS Code, нажмите **Go Live** и откройте `index.html`.

Также можно использовать:

```bash
npx serve .
```

После запуска откройте адрес, который покажет сервер, например:

```text
http://localhost:3000
```

## Работа с товарами

Товары находятся в файле `data/data.json`. Каждый товар содержит:

- `id` - уникальный идентификатор;
- `name` - название товара;
- `price` - новая и старая цена;
- `image` - путь к изображению;
- `availability` - наличие по городам;
- `type` - категории для фильтрации;
- `rating` - рейтинг;
- `goodsOfDay` - признак товара дня.

## Основные файлы JavaScript

- `js/main.js` - инициализирует общие компоненты и страницы;
- `js/pages/catalog.js` - отвечает за каталог, загрузку товаров, фильтрацию, сортировку и пагинацию;
- `js/pages/checkout.js` - инициализирует страницу оформления заказа;
- `js/components/Basket.js` - отображение и управление корзиной;
- `js/services/basketService.js` - бизнес-логика корзины;
- `js/services/basketStorage.js` - сохранение корзины в браузере;
- `js/api/productsApi.js` - загрузка товаров из JSON.

## Примечания

- Основные стили лежат в `scss/`, готовый CSS подключается из `css/style.css`.
- Для корректной работы каталога нужен локальный сервер.
- Проект рассчитан на современные браузеры с поддержкой ES Modules.
