# Briaton — демонстрационный шаблон интернет-магазина

Учебный адаптивный сайт каталога светотехники на HTML, SCSS и JavaScript.
Основа: оригинальный проект Briaton. Подходит как пример интерфейса в портфолио;
**не является работающим интернет-магазином без серверной интеграции**.

## Что реализовано

- Каталог с локальными демонстрационными товарами из `data/data.json`.
- Фильтры категорий и наличия, сортировка и пагинация.
- Карточка товара `product.html?id=<id>`, доступная по кнопке «Подробнее».
- Добавление и удаление товаров, сохранение корзины в localStorage.
- Страница оформления заказа с валидацией.
- Форма обращения с валидацией; FAQ, слайдер, выбор города и меню.
- Адаптивный интерфейс и базовая доступность.
- Главный экран, переходы по категориям, уведомление с названием добавленного товара, кнопка возврата наверх и анимации с учётом `prefers-reduced-motion`.

## Важное о демо-режиме

**Заказы и обращения НЕ отправляются**. API не подключён. После валидации
показывается честное демо-сообщение, а корзина сохраняется. Тестовый endpoint
httpbin.org удалён: данные покупателей не должны отправляться сторонним сервисам.

Подключение реального API начинается с `js/config.js`. Перед коммерческим
использованием необходимы собственный backend, серверная проверка цены/остатков,
защита от спама, безопасная обработка персональных данных, юридические документы,
лицензии на бренд/изображения и работающий процесс обработки заказов.

## Запуск

```bash
npm ci
npm run check
npm run build:css
npx serve .
```

Откройте адрес локального сервера. Не открывайте `index.html` через `file://`:
`fetch` для `data/data.json` требует HTTP.

## Стек

HTML5, SCSS, ES Modules, Swiper, Tippy.js, JustValidate, ESLint, Prettier.

## Структура

- `index.html` — каталог.
- `product.html` — карточка товара.
- `checkout.html` — оформление заказа в демо-режиме.
- `privacy.html`, `personal-data.html` — справочные страницы, не юридические шаблоны.
- `js/config.js` — конфигурация endpoints; по умолчанию `null`.
- `js/services/submitRequest.js` — отправка только к явно настроенному API.
- `js/config/brand.js` — идентификатор бренда, название, локаль и валюта.
- `js/services/basketService.js` и `basketStorage.js` — корзина. В хранилище бренда лежат версия схемы, ID и количество. Названия, фотографии и цены берутся из каталога.
- `js/pages/` — логика страниц.
- `scss/style.scss` — точка входа SCSS. `npm run build:css` обновляет `css/style.css`, который подключают все страницы и проверяет CI.
- `data/data.json` — локальные демонстрационные данные.

## Проверка

```bash
npm run lint
npm run check
npm test
npm run build:css
```

## Кастомизация

Измените бренд, тексты, контакты, валюту, изображения и товары.
Файлы `privacy.html` и `personal-data.html` требуют отдельного
юридического согласования перед запуском настоящего магазина. Не заявляйте
пользователям, что заказ принят, пока сервер не подтвердил его сохранение.

## Защита демо-страниц

Публичные контакты и ссылки на чужие социальные профили удалены из шаблона.
Кнопки отправки форм изначально отключены и активируются только после
инициализации валидации JavaScript. Таким образом, при отсутствии JS браузер
не отправит введённые данные обычным POST-запросом.
